# Proxy Retranslator

Простое Windows-приложение на C#, которое автоматически находит IP телефона, подключённого по USB, и поднимает локальный HTTP-прокси на `127.0.0.1:10811`. Дальше оно же включает системный прокси Windows и при желании перенаправляет весь трафик в **HAPP** на телефоне.

Идея простая: телефон по USB даёт интернет, а приложение избавляет от ручного перещёлкивания адаптеров, прокси и портов.

## Что умеет

- **Автопоиск IP телефона** — находит активный Ethernet-адаптер USB-модема (Android RNDIS, Apple Mobile Device Ethernet, CDC и т.п.) и берёт его шлюз.
- **Локальный HTTP/CONNECT прокси** на `127.0.0.1:<порт>` (по умолчанию `10811`).
- **Автовключение системного прокси Windows** — пишет `ProxyEnable=1`, `ProxyServer=127.0.0.1:<порт>` в реестр и дёргает `InternetSetOption`, чтобы изменения применились мгновенно.
- **Опциональная переадресация в HAPP** — весь трафик идёт в HAPP-прокси на телефоне.
- **Консоль отладки** прямо в окне: видно каждое соединение, куда уходит и что отвечает upstream.
- **Аккуратная очистка** — при остановке и закрытии системный прокси возвращается в исходное состояние.

## Требования

- Windows 10 / 11
- .NET Framework 4.7.2+ (или .NET 6/7/8 Windows)
- Visual Studio 2022 (Community хватит)

Сборка:

1. Открыть `ProxyBackdoorColledge.sln` в Visual Studio.
2. **Build → Rebuild Solution**.
3. Запустить (`F5`) или взять `.exe` из `bin\Debug\`.

Права администратора **не нужны** — работаем в `HKCU`, текущем пользователе.

## Подключение

### Вариант 1. Просто через USB-модем (без HAPP)

Для случая, когда достаточно того, что телефон раздаёт интернет по USB.

1. **Подключите телефон к ПК по USB-кабелю.**
2. **Включите на телефоне «USB-модем»** (USB tethering):
   - Android: `Настройки → Точка доступа и модем → USB-модем`.
   - iOS: `Настройки → Режим модема → Разрешить другим`.
3. **Нажмите «Определить автоматически»** в приложении.
   - В логе появятся все кандидаты-адаптеры, а в поле «IP телефона» подставится нужный шлюз.
4. **Нажмите «Запустить прокси».**
   - Приложение поднимет локальный прокси на `127.0.0.1:10811`.
   - При включённой галочке **«Автоматически включать системный прокси Windows»** — само впишет адрес в настройки Windows.
   - Открывайте браузер, всё пойдёт через телефон.

Если хочется без HAPP, просто **оставьте галочку «Перенаправлять трафик на HAPP» снятой**. Трафик будет идти в целевые хосты напрямую, но через ваш локальный прокси — пригодится для логирования и подмены.

### Вариант 2. С HAPP (обход блокировок, кастомные правила)

Для случая, когда HAPP на телефоне обрабатывает трафик (обход блокировок, маршрутизация, свои правила).

1. **Подключите телефон к ПК по USB-кабелю.**
2. **Включите на телефоне «USB-модем»** (USB tethering).
3. **Нажмите «Определить автоматически»** в приложении.
   - Поле «IP телефона» заполнится шлюзом USB-адаптера.
4. **В настройках HAPP на телефоне включите «Разрешить подключения из LAN»** (см. Скриншот 2).
   - Порт HTTP-прокси оставьте по умолчанию (`10808`), если вы его не меняли.
5. **Запустите VPN в клиенте HAPP** (кнопка «Подключиться» / «Start» в главном экране).
6. **В приложении поставьте галочку** «Перенаправлять трафик на HAPP (телефон)».
   - Поле «HAPP порт» разблокируется. Если порт не меняли в HAPP — оставьте `10808`.
7. **Нажмите «Запустить прокси».**
   - Приложение поднимет локальный прокси, включит системный прокси Windows и начнёт пересылать трафик в HAPP на телефоне.
8. Откройте браузер и проверьте, что трафик идёт через HAPP (например, по логу в окне приложения — там будут строки `→ Перенаправление на HAPP ...`).

## Настройки

| Поле | По умолчанию | Описание |
|---|---|---|
| **Порт локального прокси** | `10811` | Порт, который слушает приложение. То же значение прописывается в системный прокси Windows. |
| **IP телефона** | `10.116.148.146` | Шлюз USB-адаптера. Находится кнопкой «Определить автоматически». |
| **HAPP порт** | `10808` | HTTP-порт HAPP. Поле активно только при включённой галочке перенаправления. |
| **Автоматически включать системный прокси Windows** | вкл | Если включено — приложение само правит настройки Windows. |
| **Автообновление при запуске** | вкл | Если включено — при старте прокси заново ищет IP телефона. |
| **Перенаправлять трафик на HAPP** | выкл | Пересылать весь трафик в HAPP вместо прямого подключения. |

## FAQ / Диагностика

**Q. Автопоиск выбрал домашний роутер, а не USB-модем.**
Отключите домашний кабель на время работы — или снимите галочку «Автообновление при запуске» и впишите IP вручную. Автопоиск отдаёт приоритет адаптерам, в описании которых есть `Remote NDIS`, `RNDIS`, `USB Ethernet`, `Android`, `Apple Mobile Device`, `Internet Sharing`, и адаптерам с «нестандартным» шлюзом (не `192.168.x.1`).

**Q. В логе `HAPP отказал в туннеле: HTTP/1.1 502 Bad Gateway`.**
Это **не** ошибка приложения. HAPP получил CONNECT, попытался установить соединение с целевым хостом — и не смог. Обычно причина: на телефоне нет интернета, или HAPP сам не может достучаться до целевого сервера. Проверьте интернет на телефоне и логи самого HAPP.

**Q. В логе `ОШИБКА подключения к <IP>:<порт>: ...`.**
Приложение не смогло открыть TCP-соединение с HAPP. Проверьте:
- IP телефона указан правильно (это шлюз USB-адаптера, а не ваш адрес);
- USB-модем включён;
- HAPP запущен и слушает нужный порт;
- В HAPP включено **«Разрешить подключения из LAN»**.

**Q. Приложение закрыл, а системный прокси Windows остался включён.**
Это возможно при аварийном завершении. Откройте `Пуск → Параметры → Сеть и Интернет → Прокси-сервер` и выключите тумблер вручную. При нормальном закрытии окна приложение само всё откатывает.

**Q. iPhone не находится автоматически.**
Убедитесь, что установлены драйверы Apple (iTunes или Apple Devices с сайта Apple). Без них Windows не создаёт виртуальный Ethernet-адаптер `Apple Mobile Device Ethernet`, и искать нечего.

**Q. Хочу использовать без HAPP, как обычный локальный прокси.**
Снимите галочку «Перенаправлять трафик на HAPP» — приложение будет проксировать напрямую в целевые хосты. Полезно, если нужно логировать трафик или навесить свои правила в `ProxyServer.HandleClientAsync`.
